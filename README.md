# IndoWare

IndoWare is basically WarioWare but Indian.

It's a collection of quick little minigames based around Indian stuff. You get a few seconds to figure out what to do before the timer runs out.

Made with Godot.

## Play

You can play the web version here:

https://jayflixy.itch.io/indoware

## Running the Project

1. Install [Godot](https://godotengine.org/)
2. Clone this repository
3. Open `project.godot` in Godot
4. Press Play

## Building

1. Open the project in Godot
2. Go to **Project → Export**
3. Add the platform you want to build for
4. Install the export templates if Godot asks
5. Choose where you want to save the build
6. Click **Export Project**
